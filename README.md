# JAVA- YEAR 2

This repository contains the practical exercises and assignments I completed in Java during the second year of my Bachelor's degree in Computer Science at Haute École Léonard de Vinci.

The goal of these exercises was to progressively apply the concepts covered in class and improve my Java programming skills.

## Topics Covered

Throughout the different workshops, I worked on:

- Object-Oriented Programming (OOP)
- Classes and objects
- Inheritance and polymorphism
- Interfaces
- Java Collections
- Exception handling
- Lambda expressions
- Java Streams
- Data manipulation and processing
- Java project organization

## Repository Content

The repository is organized into several workshops completed throughout the academic year.

Each workshop focuses on practicing different Java concepts through exercises and small projects.
